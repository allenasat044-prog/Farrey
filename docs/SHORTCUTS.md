# Farrey shortcuts

Use Cmd on macOS, Ctrl on Windows and Linux.

| Shortcut | Action |
|---|---|
| Cmd/Ctrl+N | New sticker |
| Cmd/Ctrl+O | Open a file in this sticker |
| Cmd/Ctrl+E | Toggle edit / preview |
| Cmd/Ctrl+F | Find in note |
| Enter / Shift+Enter | Next / previous match (in the find box) |
| Cmd/Ctrl+G | Next match (Shift for previous) |
| Esc | Close find, or the color popover |
| Cmd/Ctrl+Shift+P | Toggle float on top |
| Cmd/Ctrl+W | Close this sticker (its file is kept) |
| Double-click title bar | Shade / unshade |

Tray / menu bar icon: New Sticker, Show All, Hide All, Quit.
