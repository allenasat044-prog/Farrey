# Farrey shortcuts

Use Cmd on macOS, Ctrl on Windows and Linux.

| Shortcut               | Action                                         |
| ---------------------- | ---------------------------------------------- |
| Cmd/Ctrl+N             | New sticker (normal note)                      |
| Cmd/Ctrl+Shift+M       | Switch between normal and README mode          |
| Cmd/Ctrl+B / I / U     | Bold / italic / underline (normal mode)        |
| Cmd/Ctrl+O             | Open a Markdown file (switches to README mode) |
| Cmd/Ctrl+E             | Toggle edit / preview (README mode)            |
| Cmd/Ctrl+Shift+O       | Table of contents (README mode)                |
| Cmd/Ctrl+F             | Find in note                                   |
| Enter / Shift+Enter    | Next / previous match (in the find box)        |
| Cmd/Ctrl+G             | Next match (Shift for previous)                |
| Esc                    | Close find, or the color popover               |
| Cmd/Ctrl+Shift+P       | Toggle float on top                            |
| Cmd/Ctrl+W             | Close this sticker (its file is kept)          |
| Double-click title bar | Shade / unshade                                |

Tray / menu bar icon: New Sticker, Show All, Hide All, Quit.

## Global hotkeys (work from any app)

| Default              | Action                    |
| -------------------- | ------------------------- |
| Cmd/Ctrl+Alt+Shift+F | Show or hide all stickers |
| Cmd/Ctrl+Alt+Shift+N | New sticker               |

Change them in `settings.json` (see the README). Not available on Linux Wayland.
